HMZA CREW WEBSITE — QUICK START

1. Extract the ZIP file.
2. Open index.html in a modern browser, or upload the whole folder to a static host.
3. The included AI-generated banner is in assets/ai-gang-banner.png.
4. Search and demo cart work in the browser.

IMPORTANT ABOUT LOGIN
The Google button is a visual/demo button. Real Google sign-in requires Firebase Authentication:
- Create a Firebase project at https://console.firebase.google.com/
- Add a Web App and copy its Firebase config.
- Enable Authentication > Sign-in method > Google.
- Add Firebase SDK initialization and GoogleAuthProvider sign-in code to script.js.
- Configure authorized domains in Firebase Authentication.
Never store private credentials or service-account keys in front-end code.

This is a fictional character storefront. It does not sell real people. The included AI image is a concept banner; individual card crops use different parts of that image. For best results, replace those crops with separate AI portraits you have rights to use.
